## `> principles --engineering`

```text
Threat model → Secure defaults → Deterministic controls → Automated evidence
             → Observe → Retest → Improve
```

- **Architecture:** explicit boundaries, Clean/Hexagonal Architecture and least privilege.
- **Quality:** TDD, unit/integration/E2E tests and measurable quality gates.
- **Delivery:** reproducible CI/CD, pinned dependencies and supply-chain controls.
- **Operations:** structured logs, metrics, tracing, SLOs and actionable runbooks.
- **Security:** fail-closed behavior, evidence-based findings and mandatory retesting.
- **AI:** models assist analysis; deterministic controls retain high-risk decisions.
